## 5. Evaluators for LangSmith

Replace `e2e_quality` entirely. Its criterion ("alignment with golden answer") duplicates correctness. Define metrics on the atomic facts instead:

| Key | Type | Rule |
|---|---|---|
| `completeness` | judge, per fact | entailed facts ÷ required facts |
| `correctness` | same judge call | 1 − (contradicted facts ÷ required facts). Terse-but-right means high correctness, low completeness: that is the distinction reviewers asked for |
| `critical_error` | same call | 1 if any `must_not_say` item is stated or a dose number is wrong. Report counts (covers the "harmful outputs" limitation) |
| `faithfulness` | judge, per claim | supported claims ÷ claims, against the **full, untruncated** context given to the synthesizer. Call it "claim support rate", never hallucination rate (A7). N/A for no_rag |
| `context_recall` | judge, per fact | gold facts found in all retrieved context (graph + vector), not graph only |
| `context_precision` | judge, per item | relevant retrieved items ÷ retrieved items. This is the mechanism by which routing should help |
| `router_label` | code | exact / under-routed (missing a needed source) / over-routed, vs gold route. Adaptive arms only |
| `cypher_exec_success` | code | Cypher generated, executed without error, returned records. Gives the Cypher failure rate |
| `citation_validity` | code | every `(n)` maps to the reference list and the evidence index; sentence-coverage rate |
| `refiner_delta` | judge (full arms) | Run completeness, correctness and faithfulness on `draft_answer` and `final_answer`. Report trigger rate and "new error introduced" (a fact entailed in the draft but missing or contradicted after refining) |
| latency, tokens, cost | automatic | From the LangSmith run tree. Report P50/P95 |
| pairwise preference | offline | Adaptive vs Always-Both, position-swapped, over stored outputs. Replaces E2E quality as the "overall" metric |

Router stability (A5) doesn't need a full run. Call the router alone 5 times on all 50 questions and report the identical-choice rate.

**Judge rules:**
- Use structured output, not "reply with an integer".
- One label per fact.
- The judge may use only the listed facts, not its own medical knowledge.
- Calibrate on the dev set, not the test set.
- Prefer a stronger judge than 4o-mini for the primary score, and keep 4o-mini as a robustness check.

- **H1:** adaptive_lite is non-inferior to always_both on completeness and correctness (margin −0.10).
- **H2:** adaptive_lite has lower median latency, tokens and cost.

Fifty questions can only resolve differences of about 0.10 (assuming a paired SD of ~0.25; confirm from your pilot). Anything smaller is exploratory. If Always-Both wins on quality in the "both" stratum, report it. The honest framing then is "routing buys efficiency at little or no quality cost."

Method: average the 3 repetitions per question, bootstrap over questions for 95% CIs, run a paired Wilcoxon test, and apply Holm correction across the pre-specified comparisons. Also report mean ± SD across the three run-level means.

```python
# workflows/factory.py
from langgraph.graph import StateGraph, START, END
from core.state import GraphState   # add: draft_answer: Optional[str]
from nodes.graph_retriever_chain import GraphRetrieverChain
from nodes.vector_retriever import VectorRetriever
from nodes.router import Router
from nodes.synthesizer import synthesizer
from nodes.fallback_to_vector import fallback_to_vector
from nodes.hallucinaton_checker import hallucination_grader, hallucination_decision
from nodes.refiner_node import refiner_node
from nodes.citation_agent import citation_agent

T = {"graph": ["graph_retriever"], "vector": ["vector_retriever"],
     "both": ["graph_retriever", "vector_retriever"]}

def build(route="adaptive", fallback=False, checker=False):
    """route: adaptive | oracle | graph | vector | both. Web search deliberately absent."""
    g, gr, vr = StateGraph(GraphState), GraphRetrieverChain(), VectorRetriever()
    g.add_node("router", Router if route == "adaptive" else
               (lambda s: {"router_choice": s["router_choice"] if route == "oracle" else route}))
    g.add_node("graph_retriever", gr.graph_retriever_node)
    g.add_node("vector_retriever", vr.vector_retriever_node)
    g.add_node("synthesizer", synthesizer)
    g.add_node("citation_agent", citation_agent)

    g.add_edge(START, "router")
    # real_time has no web node here -> vector; the choice is still logged for router metrics
    g.add_conditional_edges("router", lambda s: T.get(s["router_choice"], T["vector"]),
                            ["graph_retriever", "vector_retriever"])
    if fallback:
        g.add_conditional_edges("graph_retriever", fallback_to_vector,
                                {"vector_retriever": "vector_retriever", "evidence_gate": "synthesizer"})
    else:
        g.add_edge("graph_retriever", "synthesizer")
    g.add_edge("vector_retriever", "synthesizer")

    if checker:
        g.add_node("grader", lambda s: {**hallucination_grader(s), "draft_answer": s["final_answer"]})
        g.add_node("refiner", refiner_node)
        g.add_edge("synthesizer", "grader")
        g.add_conditional_edges("grader", hallucination_decision,
                                {"end": "citation_agent", "refiner": "refiner"})
        g.add_edge("refiner", "citation_agent")
    else:
        g.add_edge("synthesizer", "citation_agent")
    g.add_edge("citation_agent", END)
    return g.compile()

ARMS = {"vector_only": dict(route="vector"), "graph_only": dict(route="graph"),
        "always_both": dict(route="both"),
        "adaptive_lite": dict(route="adaptive", fallback=True),
        "adaptive_full": dict(route="adaptive", fallback=True, checker=True),
        "always_both_full": dict(route="both", checker=True),
        "oracle_router": dict(route="oracle", fallback=True)}
```

**One judge call yields three metrics (replaces `answer_correctness`, `completeness` and `e2e_quality`):**

```python
import re
from typing import Literal
from pydantic import BaseModel
from langchain_openai import ChatOpenAI

class Labels(BaseModel):
    labels: list[Literal["entailed", "missing", "contradicted"]]  # one per required fact, in order
    must_not_say_violated: bool

_judge = ChatOpenAI(model=JUDGE_MODEL, temperature=0).with_structured_output(Labels)

def fact_scores(run, example):
    facts = example.outputs["required_facts"]; n = len(facts)
    ans = re.split(r"###\s*References", run.outputs["final_answer"])[0]
    facts_txt = "\n".join(f"{i+1}. {f}" for i, f in enumerate(facts))
    r = _judge.invoke(
        f"Question: {example.inputs['question']}\nRequired facts:\n{facts_txt}\n"
        f"Must NOT say: {example.outputs['must_not_say']}\nAnswer:\n{ans}\n\n"
        "Label each required fact: entailed (stated or clinically equivalent), "
        "missing (not addressed), contradicted (incompatible statement). "
        "Judge ONLY against the listed facts, not your own medical knowledge.")
    lab = (r.labels + ["missing"] * n)[:n]
    return {"results": [
        {"key": "completeness", "score": lab.count("entailed") / n},
        {"key": "correctness", "score": 1 - lab.count("contradicted") / n},
        {"key": "critical_error", "score": int(r.must_not_say_violated)}]}
```

```python
    boots = np.random.default_rng(seed).choice(d, (B, len(d))).mean(1)
```
